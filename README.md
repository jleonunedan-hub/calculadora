# Calculadora Web

Calculadora funcional hecha con HTML, CSS y JavaScript.

## Demo

[Ver calculadora online](https://TU_USUARIO.github.io/TU_REPO/)

## Funciones

- Suma, resta, multiplicación y división
- Porcentaje
- Cambio de signo
- Soporte para teclado
- Diseño responsive

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Uso local

Descarga el repositorio y abre `index.html` en el navegador.
